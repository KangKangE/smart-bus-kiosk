# 말하는 스마트 정류장

노약자와 외국인을 위한 음성 기반 스마트 버스 정류장 안내 키오스크.

## 실행 방법

빌드 과정 없이 `index.html`을 브라우저(Chrome/Edge 권장)에서 열면 바로 실행됩니다.

> 음성 인식(마이크)은 브라우저 보안 정책상 `file://`에서는 제한될 수 있습니다.
> 마이크까지 테스트하려면 로컬 서버로 실행하세요:
>
> ```
> python -m http.server 8000
> ```
>
> 이후 http://localhost:8000 접속. (음성 인식이 안 되는 환경에서는 화면의 예시 질문 버튼으로 체험 가능)

## 파일 구성

- `index.html` — 페이지 뼈대
- `style.css` — 키오스크 전체 스타일 (반응형 포함)
- `app.js` — 화면 전환, 다국어(한/영/일/중), 음성 인식(Web Speech API), 음성 안내(TTS), 설정 저장(localStorage)
- `favicon.svg` — 파비콘

## 주요 기능

- **홈**: 음성 버튼 + 빠른 메뉴 3종 (도착 시간 / 길찾기 / 정류장 정보)
- **음성 인식**: "눌러서 말하기" → 인식된 문장에 따라 화면 자동 이동
  - "도착", "470", "버스 언제" → 도착 정보
  - "정류장", "현재 위치" → 정류장 정보
  - 그 외 → 길찾기
- **버스 도착 시간**: 실시간 도착 목록(시연 데이터), 음성 안내 듣기
- **목적지 길찾기**: 추천/대안 경로 카드 → 상세 경로(탑승 단계 + 지도)
- **정류장 정보**: 현재 위치 지도와 주변 시설
- **언어 선택**: 한국어 / English / 日本語 / 中文 — 화면·음성 모두 전환
- **관리자 설정**(하단 "관리자 설정"): 정류장 이름·ID·주소, AI 기본 프롬프트, API URL 설정 → localStorage에 저장
- 90초 동안 조작이 없으면 자동으로 홈 화면 복귀

## Gemini AI 음성 연동

1. https://aistudio.google.com/apikey 에서 무료 API 키 발급 (Google 계정만 있으면 됨)
2. 사이트 하단 **관리자 설정** → **Gemini AI 음성 연동**에 키 입력 → **연결 테스트** → **변경사항 저장**
3. 이후 "눌러서 말하기"로 질문하면 Gemini(`gemini-2.5-flash-lite`)가 질문 의도를 파악해
   알맞은 화면으로 이동하고, 답변을 현재 선택된 언어의 음성으로 읽어줍니다.
   - 관리자 설정의 "AI 기본 프롬프트"가 시스템 프롬프트로 함께 전달됩니다.
   - 키가 없거나 호출이 실패하면 기존 키워드 방식으로 자동 대체됩니다.
   - 키는 이 기기의 localStorage에만 저장되며 코드에 포함되지 않습니다.

## 실시간 버스 데이터 연동 (배포 후)

- `api/arrivals.js` — Vercel 서버리스 프록시. 공공데이터포털의
  「서울특별시_버스도착정보조회 서비스」·「서울특별시_정류소정보조회 서비스」 활용신청 후,
  Vercel 환경변수 `BUS_API_KEY`에 일반 인증키(Decoding)를 등록하면
  `/api/arrivals?arsId=01120` 형태로 실시간 도착 정보를 받을 수 있습니다.
- 로컬(file://)에서는 프록시가 동작하지 않으며, 시연 데이터로 표시됩니다.

## 배포 (Vercel)

1. GitHub에 이 폴더 전체를 저장소로 업로드 (`api` 폴더 포함)
2. vercel.com → Add New Project → 저장소 Import → Framework Preset: **Other** → Deploy
3. Settings → Environment Variables에 `BUS_API_KEY` 등록 후 Redeploy
4. 배포된 HTTPS 주소에서는 마이크(음성 인식)도 정상 동작합니다.
